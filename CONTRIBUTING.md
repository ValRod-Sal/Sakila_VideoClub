# Contribuir a Club Sakila

1. Actualiza tu rama desde master y crea una rama de trabajo.
2. Mantén los módulos CSS y JavaScript existentes.
3. Comprueba los flujos de socio y administrador, tanto en demo como en servidor.
4. No publiques archivos .env, claves API ni bases con datos personales.
5. Documenta los cambios y abre un pull request para revisión del equipo.
6. Conserva atribuciones y declara la asistencia de IA según las reglas académicas.
